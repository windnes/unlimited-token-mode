# 运行报告（run report）—— 无限tokenPTC版

> 契约 7（可证伪收工）的载体。**"完成"不是一句声明，是一组能失败的检查及其真实输出。**
> 校验：`python scripts/ptc_lint.py <本文件> --kind report`
> 严格校验：追加 `--strict`。
>
> PTC 前提：只有 `return` 与 `console.log` 的内容进入对话，其余中间结果全部丢弃。
> 所以本报告里每一条证据，都必须是某个程序 `return` 出来的**原始值**；
> 程序内部跑过但没 `return` 的检查，读者看不到，也就不算证据。
>
> 写报告时禁止使用任何含糊断言（完整禁用词表见 `SKILL.md` 的禁用清单）。
> 每条"已完成"后面必须跟一条**如果实现错了就会失败**的命令输出。

## 2. 完成判据 → 验证命令 → 真实输出

> 从 task brief 的 §2 逐条搬过来，把"期望输出"换成**实际输出**。
> 没有真实输出 = 该条判据未验证，必须移到 §3。
>
> **证据必须是程序 `return` 出来的原始值，不是程序自己算的 pass。**
> 允许的证据形态：`exit=` 退出码、原始输出片段、diff、文件内容。
> 不允许的证据形态：`{ ok: true }`、`{ allPass: true }`、`{ passed: 3 }` ——
> 这类"自证判决"（P2）无法被读者推翻，等同于没有证据。
> 证据可以截断，但不得改写；截断处必须标明截断，且不得在截断后声称"跑完了"（P6）。

**若触顶**：
1. 说明触顶发生在哪个程序、那一段做了什么、按优先级牺牲了什么、哪些判据因此未验证
